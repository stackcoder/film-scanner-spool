# Film Scanner Spool

![Model preview](https://github.com/stackcoder/film-scanner-spool/releases/latest/download/preview.png)

[Download STL](https://github.com/stackcoder/film-scanner-spool/releases/latest/download/scanner-spool.stl)

Filmholder to scan a whole (uncut) filmstrip at once.

Suitable for:
- Reflecta ProScan 3600
- Reflecta ProScan 4000
- Mediax WorkScan 3600 Pro
- Mediax WorkScan 4000 Pro
- Microtek FilmScan 3600
- Pacific Image PrimeFilm 3600PRO

This project provides independently developed accessories for the devices listed above.
